# gp64 0.2.3 — 2026-10-15

More of the drawing moves to the GPU: smooth and area scaling, the F12 menu
and the REC light no longer force the window back to the CPU, and the
release executable is smaller.

## Changed

- Smooth and area scaling now run on the graphics card on Windows and macOS, with output identical to the CPU scaler. Only the CRT filter is still drawn on the CPU.
- Opening the F12 menu or recording no longer makes gp64 redraw the whole window on the CPU every frame; the menu and REC light are drawn by the graphics card as layers.
- The Windows executable is about 1.3 MB smaller, and emulation uses slightly less host CPU.

## Downloads

- Windows x64: `gp64-v0.2.3-windows-x86_64.zip`
- Apple Silicon macOS: `gp64-v0.2.3-macos-arm64.tar.gz`

Each archive holds the `gp64` executable (`gp64.exe` on Windows), `LICENSE`
(GPL-3.0) and `THIRD_PARTY_LICENSES.txt`. Builds are unsigned: macOS is not
Developer ID signed or notarized; Windows is not Authenticode signed.
