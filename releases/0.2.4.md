# gp64 0.2.4 — 2026-10-15

DOS programs now see a 486, setup programs that looked hung now show their
menus, and modem games played over a network keep pace instead of falling
further behind.

## Added

- DOS programs now run on an emulated 486 instead of a 386, so setup programs that pick settings by CPU choose their 486 options.
- A recording that stops early now writes the reason to `gp64.log`, so you can see why even when gp64 was started from the desktop.

## Fixed

- Setup programs that clear the screen using the colour under the cursor no longer show a black window that looks hung; DOS programs now start on a blank light-grey text screen, as on a real PC.
- The window no longer flashes white for about half a second at startup on Windows; it appears only once it holds a black frame.

## Changed

- Once a modem call between two copies of gp64 0.2.4 or later is connected, the copies send the game's data instead of the modem's sound. Network hiccups no longer make the link fall further behind for the rest of the call. Calls to older versions still work as before.

## Downloads

- Windows x64: `gp64-v0.2.4-windows-x86_64.zip`
- Apple Silicon macOS: `gp64-v0.2.4-macos-arm64.tar.gz`

Each archive holds the `gp64` executable (`gp64.exe` on Windows), `LICENSE`
(GPL-3.0) and `THIRD_PARTY_LICENSES.txt`. Builds are unsigned: macOS is not
Developer ID signed or notarized; Windows is not Authenticode signed.
