# gp64 0.2.2 — 2026-10-15

Lighter on the CPU: the window is drawn on the GPU, and the emulator stops
far less often to service the hardware, which helps most on laptops and
high-resolution screens.

## Changed

- On Windows and macOS the window is drawn by the graphics card with the integer scaler, instead of being scaled on the CPU every frame. If no graphics card can be used (for example over Remote Desktop), gp64 draws on the CPU as before.
- The window is redrawn only when the picture changes, and drawing no longer holds up the emulation.
- Programs that poll hardware ports in tight loops run with much less host CPU, with the same timing as before.
- The speed line in the diagnostics log reports I/O service exits instead of every port access.

## Fixed

- Sine, cosine, FSINCOS and FPTAN of an infinity no longer overwrite the FPU stack when the program has unmasked invalid-operation exceptions.

## Downloads

- Windows x64: `gp64-v0.2.2-windows-x86_64.zip`
- Apple Silicon macOS: `gp64-v0.2.2-macos-arm64.tar.gz`

Each archive holds the `gp64` executable (`gp64.exe` on Windows), `LICENSE`
(GPL-3.0) and `THIRD_PARTY_LICENSES.txt`. Builds are unsigned: macOS is not
Developer ID signed or notarized; Windows is not Authenticode signed.
